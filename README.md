# Portuguese-Bank-Marketing
Project Analysis

The Portuguese Bank Marketing project focuses on analyzing customer data from direct marketing campaigns conducted by a Portuguese banking institution between May 2008 and November 2010. The main objective is to understand customer behavior and identify the factors influencing the subscription of term deposits. Exploratory Data Analysis (EDA) is performed to examine customer demographics, campaign details, previous contact outcomes, and economic indicators. Machine learning algorithms are applied to predict whether a customer will subscribe to a term deposit. Different models are evaluated and compared using performance metrics to identify a suitable predictive model. The analysis also provides insights into customer preferences and campaign effectiveness.

Project Context

The project belongs to the Finance and Banking domain and aims to improve the effectiveness of bank marketing campaigns. The dataset contains customer information such as age, job, marital status, education, loans, contact details, campaign history, and social-economic indicators. The target variable, `y`, indicates whether a customer subscribed to a term deposit (`yes` or `no`). By using data analysis and predictive modeling, the bank can identify potential customers, optimize marketing strategies, reduce unnecessary calls, and improve customer subscription rates. The project combines data analytics and machine learning to support data-driven marketing decisions.
